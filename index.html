    音訊狀態：尚未啟動（按 POWER）

    沒有吉他：選 DEMO RIFF 聽內建樂句，或 LOAD FILE 載入自己的音檔（吉他 DI 乾聲最適合）；按 PLUCK 撥空弦試調音器，按 CHORD 刷基本和弦（會自動停止樂句）。

    接吉他：吉他接 USB 錄音介面，選 LIVE INPUT 並允許使用麥克風；請戴耳機避免回授。延遲取決於瀏覽器和裝置，通常 10–40 ms。嵌在其他網站裡的頁面（例如 claude.ai）不能使用麥克風，請開 anyouhuang.github.io/guitar-pedalboard。

    訊號鏈：仿 POD HD500X：8 個效果格加一個音箱（Cab）方塊，由左到右依序處理。點方塊在下方編輯，雙擊開關；用滑鼠拖曳或按 MOVE 換位置；空的格子選「效果類型」就能放效果。破音類有 HD500X 的 15 種型號（名稱照 HD500X 清單，聲音是依原型機器自己做的近似模型，不是 Line 6 的原始演算法）。

    操作：旋鈕上下拖曳（按住 Shift 微調），雙擊回預設值，點一下後也可用滾輪或方向鍵；TAP 跟著拍子點 3–4 下設定速度，延遲的 Note 選音符值就會跟著速度；EQ 在最後輸出端，拖曳彩色點，游標在點上時滾輪調 Q。
